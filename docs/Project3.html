Blackjack Simulation

Simulating Blackjack win rates
Author

Andy Xiao

Blackjack, is perhaps one of the most recognizable casino games, seems like a simple game at its core. The dealer deals you two cards and shows one of theirs, each hands comes down to a decision to either hit and recieve another card or stand. This repeated decision is based on a factors such as how likely the dealer is to bust and the likeliness of creating a higher number without going over 21. This decision can be hard for newer players, and in this project, I will explore different simulations of different hands of blackjack to find the best decision in order to maximize profit.

We will start by creating a function to calculate the value of the blackjack hand. An interesting characteristic about Blackjack is that Aces can either be 1 or 11. A hand is considered soft if a hand contains an Ace and has the option to be either a 1 or 11. For example if dealt a hand 5 and 1, the hand is soft because 1 can be turned into 11 without busting. However if given a hand 5, 1, and 9, then the hand is not soft because the 1 cannot be turned into 11 without busting. To keep track of this important charateristic we can create a function to check whether the hand is soft or not.

library(tidyverse)
hand_value <- function(hand){
    total <- sum(hand)
    #checks if it can turn an Ace into an 11
    if (any(hand == 1) && total + 10 <= 21){
        total <- total + 10
    }
    return(total)
}

is_soft <- function(hand){
    soft = any(hand == 1) && sum(hand) + 10 <= 21
    return(soft)
}

Next, we need to create a function to calculate the dealer’s hand. In most Blackjack games the dealer with keep hitting until their hand is greater than or equal to 17.

set.seed(100)
#deck, 4 10's for the 3 face cards and 10
cards <- c(1:9, 10, 10, 10, 10)
dealer <- function(face_up_card){
    unknown_card <- sample(cards, 1)
    hand <- c(face_up_card, unknown_card)
    while (hand_value(hand) < 17){
        hand <- c(hand, sample(cards, 1))
    }
    return(hand_value(hand))
}

After finding the value of the dealer and player we need to find the outcome of the game. We can create a function which finds the outcome, we will track a player with with 1 and a loss with -1.

Show code 
outcome <- function(player, dealer){
    if (player > 21){
        return(-1)
    } else if (dealer > 21){
        return(1)
    } else if (dealer > player){
        return(-1)
    } else if (player > dealer){
        return(1)
    } else{
        return(0)
    }
}

library(tidyverse)
play_hand <- function(p_card1, p_card2, dealer_card, action) {
    player_cards <- c(p_card1, p_card2)
    if (action == "hit"){
        player_cards <- c(player_cards, sample(cards, 1))
    }
    outcome(hand_value(player_cards), dealer(dealer_card))
}

Once we have created a function to either hit or stand we can now create a simulation playing blackjack. We can create a dataset using expand_grid to create all possible permuations of player cards, dealer cards, and either standing or hitting. Additionally by making creating a variable reps we can repeat the simulations multiple times, for example if reps is 10, it will produce 10 rows of the same player hand and dealer hand and decision. To get more accurate data we will set reps to 500. After we have created the dataset of all possible permutations we can start simulating each row. Before this we can filter out rows to remove duplicates becuase expand_grid produces rows where card1 is 4 and card2 5 and other rows where card1 is 5 and card2 is 4. To simulate only unique values we use filter(card1 <= card2) which keeps exactly one of the two orders in which the smaller card is first. After getting only rows with unique card values we can simulate the result of each row with the play_hand function with pmap.

Show code 
reps <- 500
set.seed(200)
hands <- expand_grid(
  card1 = 1:10,
  card2 = 1:10,
  dealer_card = 1:10,
  action = c("hit", "stand"),
  rep = 1:reps
) |>
  filter(card1 <= card2) |>
  mutate(
    result = pmap_dbl(list(card1, card2, dealer_card, action), play_hand)
  )

From this simulation we are able to create a dataframe which summarizes the average result of each permutation to find the best decision after being dealt two cards with a dealer card faceup. We can use pivot_wider to turn each hit or stand row into a single row with its expected value. Next we can add a column best which chooses the higher expected value of each decision.
